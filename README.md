# Ollama4School

Private AI for schools: Windows PCs run [Ollama](https://ollama.com) and announce themselves on the Wi-Fi; Android apps find them automatically and spread students' questions across them.

- **Manual:** https://yojobama.github.io/Ollama4School/
- `OllamaServer.ps1` / `Install.cmd` – server installer
- [`android/`](android) – Java library
- [`examples/`](examples) – sample chat app and code snippets
- [`docs/`](docs) – manual source (GitHub Pages)

To publish the manual: in the repository go to **Settings → Pages → Source: GitHub Actions**.
