# Examples

| File | Shows |
|---|---|
| `ChatActivity.java` + `activity_chat.xml` + `AndroidManifest.xml` | A complete chat screen with streaming, Stop and New chat |
| `Snippets.java` | Short examples: ask, conversation, streaming, fixed PCs, emulator, pool stats, refresh, other model |
| `ConsoleExample.java` | Use `OllamaPool` from a desktop JVM |

Copy the files into an Android app that depends on the library (see the [manual](https://yojobama.github.io/Ollama4School/)).
